# Maven Toys Sales Dashboard

An interactive Power BI dashboard analysing Maven Toys sales performance across different store locations, cities and product categories.

## Key Insights

- Track total orders, revenue, profit and profit margin over time
- Analyse revenue trends by month
- Compare orders across product categories
- Compare revenue and profit by product category
- Filter the data by store location and city

## Tools Used

- Power BI
- Power Query
- DAX

## Data Source

Maven Analytics
